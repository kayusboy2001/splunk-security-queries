# Splunk Security Detection Queries

This repository contains **110+ Splunk detection queries** to help security teams identify and respond to various threats, including:

- Brute Force Attacks  
- Lateral Movement  
- Privilege Escalation  
- Data Exfiltration  
- Ransomware  
- Insider Threats  
- Phishing  
- Exploit Attempts  
- And more

## Structure

- `detection_queries_splunk.md` – Contains the full list of detection queries, organized and cleaned for direct use in Splunk.

## Usage

1. Copy the relevant query into your Splunk Search bar.
2. Modify `sourcetype`, `fields`, or thresholds to match your environment.
3. Run the query to detect security events.
